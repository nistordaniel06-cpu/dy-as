Pe o instalare nouă WordPress de test cu WP-CLI, din directorul WordPress rulează bash /cale/catre/kit/configure.sh. Alternativ instalează WooCommerce, WooCommerce Stripe Gateway, tema Storefront și apoi încarcă dy-as-theme.zip. Setează numele DY-AS, moneda EUR și activează checkout ca vizitator în Conturi și confidențialitate.

În Produse → Import încarcă catalog.csv, verifică maparea atributelor și importă imaginile cât timp sursa publică este accesibilă. Cantitățile furnizorului nu sunt publice. Confirmă stocurile, personalizarea brățării, taxele și tarifele de transport înainte de lansare. În Plăți → Stripe conectează contul de test și verifică webhook-ul și metoda Card. Rulează scenariile din META-PROMPT.md. Conectarea contului real se face de proprietar prin Stripe.
